# Wiring

Harness and interconnect diagrams — how modules physically connect inside the
cabinet.

**Intended contents**
- Point-to-point wiring diagrams and harness drawings.
- Connector pinout tables.

**Conventions**
- The authoritative textual pin map lives in `docs/Wiring.md` and must match
  `src/hardware.h`. Diagrams here illustrate that map.
