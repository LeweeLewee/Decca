# Schematics

Circuit schematics for the decca electronics.

**Intended contents**
- Source schematics (KiCad `.kicad_sch` / project files preferred; EasyEDA or
  other tools acceptable if noted).
- Exported PDFs for quick review without the CAD tool.

**Conventions**
- Keep source and exported PDF together and named consistently.
- Reflect any change here in `docs/Hardware Architecture.md` and, where it
  affects the ESP32, in `docs/Wiring.md` and `src/hardware.h`.
- Record revisions in `docs/Revision History.md`.
