# Knob Adaptors

Adaptors that mate the original front-panel knobs to modern potentiometer and
encoder shafts — preserving the period controls while using current parts
underneath.

**Intended contents**
- Parametric CAD source for each adaptor (shaft size, knob broach, tolerances).
- Print-ready STLs and per-part print notes.

**Conventions**
- Parametrise shaft diameter and fit so a variant can be produced quickly for a
  different knob or pot.
